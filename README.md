# Фолиант — информационная система книжного магазина

Учебный проект по дисциплине «Проектирование информационных систем».
Веб-приложение для управления книжным магазином: каталог, корзина и заказы,
учётные записи с ролями и раздел для начинающих авторов (подача и рассмотрение заявок).

## Технологии

| Часть | Стек |
|-------|------|
| Клиент | Vue 3, Vue Router, Vite |
| Сервер | Node.js, Express.js, REST API |
| База данных | MongoDB, Mongoose |
| Инструменты | Git/GitHub, Trello (Scrum-доска), Figma |

## Структура репозитория

```
folio-bookstore/
├── client/        клиентская часть (Vue 3 + Vite)
├── server/        серверная часть (Express + Mongoose)
├── prototype/     статический HTML/CSS-прототип интерфейса (спринт 1)
└── docs/          бэклог, план спринтов, руководство по оформлению, скриншоты
```

## Быстрый старт

Требования: Node.js 18+, npm, MongoDB (локально или Atlas).

```bash
# сервер
cd server
cp .env.example .env      # указать строку подключения к MongoDB и секрет JWT
npm install
npm run dev               # http://localhost:5000/api/health

# клиент (в другом терминале)
cd client
npm install
npm run dev               # http://localhost:5173
```

Прототип интерфейса запускается без сборки: откройте `prototype/index.html` в браузере.
