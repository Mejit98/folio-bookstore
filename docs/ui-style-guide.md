## Шрифты

- Заголовки: Georgia (запасной вариант — Liberation Serif, serif).
- Основной текст: Segoe UI (запасной вариант — Liberation Sans, Arial, sans-serif).
- Базовый размер — 16 px; заголовки: 30 / 22 / 18 px.

## Сетка и размеры

- Максимальная ширина содержимого — 1200 px, минимальная ширина страницы — 360 px.
- Точки перехода: 900 px (одна колонка, меню в строку) и 480 px (компактные отступы).
- Радиус скругления — 10 px; отступы кратны 4 px.

## Поведение форм

- Обязательные поля отмечены звёздочкой; проверка выполняется при уходе из поля и при сохранении.
- Ошибочное поле подсвечивается красным, под ним показывается пояснение.
- Поля только для чтения выделены серым фоном.
- Для действий без очевидного смысла добавляются всплывающие подсказки.
