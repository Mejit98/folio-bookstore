# План спринтов

Команда: 2 человека; ёмкость — около 25 ч в неделю. Задачи фиксируются на планировании и в ходе спринта не добавляются.

## Спринт 1. Разработка UI/UX

Цель: Согласованные макеты и работающий HTML/CSS-прототип всех экранов.
Длительность: 2 нед.; объём: 42 SP (41 ч).

| ID | Задача | SP |
|----|--------|:--:|
| S1-1 | Составить карту навигации и список экранов по ролям | 3 |
| S1-2 | Создать UI-kit: палитра, шрифты, кнопки, поля, карточки, статусы | 5 |
| S1-3 | Макеты каталога, поиска и карточки книги | 5 |
| S1-4 | Макеты входа и регистрации с состояниями ошибок | 3 |
| S1-5 | Макеты корзины, оформления заказа и истории заказов | 5 |
| S1-6 | Макеты раздела «Для авторов»: форма заявки и список заявок | 5 |
| S1-7 | Макеты панели менеджера: заявки, заказы, каталог | 5 |
| S1-8 | HTML/CSS-прототип всех экранов, адаптивная вёрстка | 8 |
| S1-9 | Локализация интерфейса и проверка форм в прототипе | 3 |
